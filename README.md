# 🏅 Olympic Analytics Dashboard

A fully interactive **Streamlit-based data analytics dashboard** for exploring and visualizing historical Olympic Games data — by country, year, gender, and sport.

---

## 🔍 Features

- 📊 **Medal Tally Explorer** (year-wise, country-wise)
- 🌍 **Nation Participation Trends** (line charts, heatmaps)
- 🧑‍🤝‍🧑 **Athlete Insights** (gender, height/weight distributions)
- 🥇 **Top Athletes & Sports Performance**
- 🧪 **Tested & Modular Design** (73% test coverage)
